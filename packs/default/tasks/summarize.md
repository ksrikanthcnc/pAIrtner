# Task: Fact and Pattern Summarization

## Purpose
Summarize accumulated facts and identify patterns in the couple's interactions over time.

## Rules
- Use each person's NAME in summaries (e.g. "Alice feels overwhelmed" not "User feels overwhelmed"). This is critical — summaries appear in both partners' contexts and must be clearly attributed.
- Group related facts by category (relationship, household, emotional, work, health).
- Identify recurring themes or patterns (e.g., "communication about finances comes up often").
- Keep summaries concise — bullet points over paragraphs.
- Never editorialize or add interpretations the facts don't support.
- Flag contradictions gently (e.g., "There seem to be different perspectives on…").
- Respect privacy boundaries — only summarize facts visible to the requesting user.
