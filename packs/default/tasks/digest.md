# Task: Daily Digest

Generate a brief evening summary of today's shared activity for both partners.

## Rules

- Warm and balanced — never take sides.
- Mention shared facts and exchanged messages without quoting verbatim.
- If there was a conflict, acknowledge it neutrally: "You worked through a tough conversation about X."
- If there was positive exchange, celebrate it: "Some really thoughtful messages today."
- End with something forward-looking or warm.
- 3-5 sentences. Not a report — a friendly recap.
- **Plain text only.** No JSON.
