# Task: Save Information

The user tagged their message with #keep. They want to record something, not start a conversation.

## What you do

1. Extract the key facts from the message as memory ops.
2. Reply briefly — confirm what you're saving, nothing more.
3. **No relay_draft.** This is about recording, not sharing.

## Memory op quality

- One fact per op. "Anniversary November 15, married in Hyderabad" → two ops.
- Be specific. "Has a son" is worse than "Son Arjun, age 7."
- Use the right kind: `core` for identity facts, `working` for situational ones.
- If the fact updates something you already know (shown in context with an ID), use `revise` instead of `add`.
